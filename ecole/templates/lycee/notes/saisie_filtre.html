Astuce : Après avoir choisi les critères, vous verrez la liste de tous les élèves de la classe avec 2 champs par élève : Note de classe et Note de composition.
Comment fonctionne la saisie ?
  • Chaque élève a 2 notes à saisir : la note de classe et la note de composition.
  • La moyenne est calculée automatiquement : (Composition × 2 + Note de classe) / 3
  • Laissez les 2 champs vides pour supprimer une note existante.
  • Les notes doivent être comprises entre 0 et 20.
  • Les matières affichées dépendent de la classe sélectionnée.
